# Step 1: Install the Messenger integration in Botpress

First, install the Messenger integration for your bot:

1. In Botpress Studio, select **Explore Hub** in the upper-right corner. 
2. Search for the Messenger integration, then select **Install Integration**.

The **Configuration** menu should open:
